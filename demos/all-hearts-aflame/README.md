# All Hearts Aflame

Generated by contractweb using the **ministry** template.

## Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "Initial site for All Hearts Aflame"
git branch -M main
git remote add origin <your-new-github-repo-url>
git push -u origin main
```

Then in the repo's Settings -> Pages, deploy from the `main` branch (root),
and add the client's custom domain under Settings -> Pages -> Custom domain.
Point the domain's DNS (A/ALIAS or CNAME records) at GitHub Pages per
GitHub's documentation, then wait for DNS to propagate and HTTPS to provision.

## Editing

The generated `index.html` and `style.css` are plain static files -- edit
them directly, or edit the source company data file and re-run:

```bash
python -m contractweb.cli new --input <company-file> --template ministry --output-dir <this-folder> --force
```
